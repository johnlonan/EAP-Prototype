1. Type A — Container Card (Correct)

aict-card base · with header, body slot, footer slot, arrow button

AI Governance

Compliance and risk overview

<slot> — body content (chart, list, etc.)
<slot name="footer"> — action-set or AI insight row
bg-base-100 border: var(--hz-color-border-default) border-radius: var(--hz-radius-parent) = 24px title: text-base-content subtitle: text-base-content/60 arrow btn: border-base-300

The radius is NOT a prop — it comes from the token applied in CSS. No consumer should pass radius="...". The footer slot is a named slot that accepts action-sets or AI insight rows.

5. Common Violations — Token Debt

Side-by-side comparisons of hardcoded values (current codebase) vs. correct token references.

❌ Hardcoded background

Property Current (wrong) Correct File
Card background bg-white bg-base-100 card.js:75
Card background bg-white bg-base-100 metric-card.js:93
Priority primary bg background: white var(--hz-color-surface-primary) priority-card.js:27

Hardcoded backgrounds break dark mode. bg-base-100 remaps automatically across all 18 modes.

Root cause fix: remove the radius prop from card.js and apply the token in CSS. All 6 wrappers are fixed without touching them.
