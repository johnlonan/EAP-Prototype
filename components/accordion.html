A change request is a formal proposal to modify any component of your IT infrastructure. All changes must be approved before implementation to minimize risk.
Changes are prioritized based on business impact, risk level, and resource availability. Emergency changes bypass the standard approval process and require retrospective review.
Standard changes require approval from the change manager and relevant service owners. High-risk changes additionally require CAB (Change Advisory Board) approval.

Hardware incidents include server failures, storage outages, network device failures, and physical damage. Use the hardware CI category when creating these incidents.
Software incidents cover application errors, database issues, API failures, and deployment problems. Attach relevant logs and error messages to help the team diagnose quickly.
