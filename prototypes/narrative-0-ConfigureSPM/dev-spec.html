Icon + circle

ElementSpec
ComponentReal <now-icon> (Seismic) — not a custom SVG
Icon name — passcircle-check-fill
Icon name — failtriangle-exclamation-fill
Circle wrapperCustom — plain div, 36px, border-radius: 50%, centers the icon. No real component covers "static icon in colored circle, no label, no click" — checked now-highlighted-value (label is required), now-badge (numeric value only), now-button-circular/now-button-iconic (interactive, wrong semantics for a passive status marker)
Circle fill — pass green 18% opacity, icon color solid rgb(75,166,107)
Circle fill — fail amber 22% opacity, icon color a darkened amber rgb(140,98,0) (manually darkened derivative — the raw amber token is too light for icon contrast on white)

Learn More (all 8 cards, not just fails)

Right-aligned, vertically centered against the full card height (align-self: center on a flex row shared with the icon circle and body) — not top-aligned with the title. Text + real <now-icon icon="open-link-right-outline">, both rgb(1,119,142). Present on every card regardless of pass/fail — tied to whether the check name is jargon-heavy, not to status.
