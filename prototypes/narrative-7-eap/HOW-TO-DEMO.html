Things that are worth calling out explicitly
✦

AI Signals

Every AI-generated insight carries a ✦ sparkle, a confidence score (High / Moderate), and a plain-language rationale. These appear inline in the backlog, as cards in the insights panel, and as banners in the home feed. They're always recommendations — the human approves.

e.g. "✦ Sprint 2 forecast: 62–80% completion range · Median 71% · High confidence · Monte Carlo, 3-sprint velocity history"
🔀

Pull Request & CI Status on Stories

Open any story at Team / Feature level (James or Dev persona, sprint board or backlog). The detail panel shows: branch name, PR number and status (open / merged), CI passing or failing, test count, reviewer status, and deployment environment. This is the developer daily experience — everything in one place without leaving the tool.

e.g. "feature/pin-fallback-handler · PR #1247 · Open · CI passing · 12/12 tests · 1 reviewer, approval pending · Deployed: staging"
◑

The Confidence Gauge

The semicircle gauge in the Insights panel is the AI's summary read on the current context — not a vanity metric. It changes per persona and per tab. It's the first thing a PM or RTE sees when they open the panel and immediately tells them whether the situation needs attention.

Ananya / Planning: "PI 26 confidence · 74% · trending down" — Dev / Kanban: "Sprint completion forecast · 64% · trending down" — Kenji: "Q3 budget committed · 82% · trending up"
☑

Definition of Done

Open a story from the sprint board (James or Dev persona). The detail panel shows a DOD checklist: Tests written · Code reviewed · Design reviewed · Docs updated · Demo recorded · No open bugs. Checked items are green; unchecked are grey. The readiness count ("2 of 8 items at DOD") also surfaces in the Insights panel so the SM sees it without opening every card.

Best shown with the "Handle fallback to PIN on failed biometric scan" story — it has a mixed DOD state and an open PR, so both features are visible at once.
📦

AI Signal Bundling

On the Backlog (Ananya persona), there's a draft Feature created by AI from 22 raw signals — emails, Teams threads, and customer tickets that all pointed to the same problem. The system clusters them and proposes one Feature rather than 22 noise items. The signal sources are visible in the detail panel.

"✦ AI bundled · 22 signals → draft Feature ready · Adaptive Biometric Re-enrolment · WSJF 12.4 — ready for your decision"
Suggested demo sequence: Start screen → Ananya (home) → Backlog (show signals + AI bundle) → open a Feature → Planning split view → switch to James → Kanban sprint board → open a story (PR + DOD) → switch to Riya → Planning (dependencies) → switch to Marcus (home, executive view).
