Setup wizard — the headline feature of N7
1

Pick your framework

Scrum, Essential SAFe, Portfolio SAFe, Kanban, or Custom. The right-hand preview updates instantly — showing the hierarchy, terminology, and cadence for that framework.

✦ Scrum is fully built out. Other frameworks show a "coming soon" preview state — set the expectation before clicking them.
2

How to set up your ART

Two paths: AI (Otto) — paste a plain-language description of your teams and Otto generates the full config. Or Manual — build it yourself.

✦ The AI path is the money shot. Type something like: "Digital Banking ART, 6 teams of 8, 10-week PIs, 2-week sprints" and watch it generate.

Spaces — team-level execution layer

Spaces are team workspaces that live inside EAP. Access them from the left nav or by switching to Dev / James persona. Each Space has up to three tabs:

Board List Docs
  • Retrospective space — Auth Team retro with Board and Docs views. Shows how a team runs structured ceremonies inside the platform.
  • Bug Register space — A List-view space for tracking bugs. Columns, filters, status pills. Good for showing non-sprint use cases.
  • Docs tab — Collaborative document editor inside a Space. Shows the "reduce context switching to Confluence" story.
Moments worth calling out in the demo
  • Home page adapts per persona — each role sees different insight cards, AI signals, and quick actions. Marcus (CDO) gets an executive brief; Dev gets a sprint board summary.
  • AI signals use ✦ sparkle — teal in AINPX, green in Sand. AI-inferred items show a confidence score. Rule-based items never do.
  • Planning tab split view — click the Split button (columns icon, top right of filter bar) to open the insights panel alongside the backlog.
  • Filter by owner — the owner chip in the filter bar narrows to "Mine Only" — each persona's items. Good for showing personalisation.
  • Hierarchy tab — shows the full Portfolio → Epic → Capability → Feature → Story tree. Use the Level dropdown to zoom in/out.
  • Setup wizard right panel — the live preview is the most designed surface in N7. Make sure it's visible; it's half the story.
